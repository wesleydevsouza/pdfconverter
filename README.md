# 📄 DOC to PDF Converter (C#)

A simple **.doc to PDF** converter built using the **Syncfusion** library.

This project was developed for study purposes, particularly to explore document processing and PDF generation in Flutter using Syncfusion — a **paid library** with a generous free community license for certain use cases.

### Features:

* Convert `.doc` files to `.pdf`
* Built using **Syncfusion Flutter PDF** and **Word** packages
* Minimal and focused UI for testing document conversion

> ⚠️ Note: Syncfusion is a commercial library. To use it beyond the free community license, a valid license is required.
